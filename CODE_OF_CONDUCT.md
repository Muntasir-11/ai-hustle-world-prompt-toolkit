# Code of Conduct

## Our Pledge

We want this project to be a welcoming, harassment-free space for everyone, regardless of experience level or background. Corrections, questions, and pull requests are all welcome here.

## Our Standards

Examples of behavior that helps this project:

- Being respectful and constructive in issues, pull requests, and discussions
- Focusing feedback on the work (a data point, a piece of wording) rather than the person
- Accepting correction gracefully when a mistake is pointed out, since that is the whole point of an open, correctable project

Examples of unacceptable behavior:

- Personal attacks, insults, or harassment of any kind
- Publishing others' private information without consent
- Spam, or pull requests submitted in bad faith, such as unrelated promotional links

## Enforcement

Instances of unacceptable behavior can be reported to muntasir@aihustleworld.com. Every report will be reviewed and result in a response appropriate to the circumstances, up to and including removing content, closing issues or pull requests, or blocking a user from the project.

## Scope

This Code of Conduct applies within project spaces, such as issues, pull requests, and discussions, and in public spaces when someone is representing the project.

Adapted in spirit from the [Contributor Covenant](https://www.contributor-covenant.org/), simplified for a small open project.
