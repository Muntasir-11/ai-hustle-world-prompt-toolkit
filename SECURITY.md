# Security Policy

This repository contains prompt-engineering templates and documentation (Markdown files). It doesn't run any code, so there's no traditional software vulnerability surface here.

## Reporting a Problem

If you find something that shouldn't be discussed in a public issue first — for example a malicious pull request, a leaked credential, or a problem with this repository's GitHub configuration — please email **muntasir@aihustleworld.com** with details instead of opening a public issue. You should get a response within a few business days.

For an ordinary correction, typo, or improvement to a template, a regular issue or pull request is the right place.

## Supported Scope

Only the `main` branch and the latest published templates are in scope. There are no software dependencies in this repository to patch.
